## com.aspose.cad.jasperreports.wmf package

The com.aspose.cad.jasperreports.wmf namespace contains the exporter implementation and related configuration beans used by JasperReports to generate WMF files from CAD sources. Use ASReportWmfExporter, ASWmfExporter, and the associated configuration classes to control output options.


## Classes

| Name | Description |
| --- | --- |
| [ASReportWmfExporter](./asreportwmfexporter/) | The Wmf file format exporter. Exports reports to the image formats. |
| [ASWmfExportConfigurationImpl](./aswmfexportconfigurationimpl/) | WMF image export configuration |
| [ASWmfExportParametersBean](./aswmfexportparametersbean/) | WMF image export parameters |
| [ASWmfExporter](./aswmfexporter/) | Exports a JasperReports document to WMF format. |
