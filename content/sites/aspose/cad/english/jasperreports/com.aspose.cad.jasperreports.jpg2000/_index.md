## com.aspose.cad.jasperreports.jpg2000 package

The com.aspose.cad.jasperreports.jpg2000 namespace groups the API elements required to integrate JPEG2000 export functionality into JasperReports. It includes configuration beans, exporter implementations, and the Jpeg2000CodecEnum for selecting compression codecs.
