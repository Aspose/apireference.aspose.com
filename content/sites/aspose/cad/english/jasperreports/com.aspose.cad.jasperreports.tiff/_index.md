## com.aspose.cad.jasperreports.tiff package

This namespace groups the TIFF export engine and related configuration beans used by JasperReports to render CAD content as high‑quality TIFF images. It includes the exporter implementation, export parameters, and configuration interfaces for fine‑tuning output.


## Classes

| Name | Description |
| --- | --- |
| [ASReportTiffExporter](./asreporttiffexporter/) | The Tiff file format exporter. Exports reports to the image formats. |
| [ASTiffExportConfigurationImpl](./astiffexportconfigurationimpl/) | The TIFF file format export configuration. |
| [ASTiffExportParametersBean](./astiffexportparametersbean/) | The TIFF file format export parameters. |
| [ASTiffExporter](./astiffexporter/) | Exports a JasperReports document to TIFF format. |
