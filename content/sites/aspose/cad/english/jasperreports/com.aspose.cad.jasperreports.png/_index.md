## com.aspose.cad.jasperreports.png package

The com.aspose.cad.jasperreports.png namespace includes exporters, configuration objects, and supporting enums that enable rendering of CAD drawings as PNG images in JasperReports. Use ASPngExporter or ASReportPngExporter together with ASPngExportConfiguration to customize color type, filter, and other export settings.


## Classes

| Name | Description |
| --- | --- |
| [ASPngExportConfigurationImpl](./aspngexportconfigurationimpl/) | The PNG file format export configuration. |
| [ASPngExportParametersBean](./aspngexportparametersbean/) | The PNG file format export parameters. |
| [ASPngExporter](./aspngexporter/) | Exports a JasperReports document to PNG format. |
| [ASReportPngExporter](./asreportpngexporter/) | The Png file format exporter. Exports reports to the image formats. |
