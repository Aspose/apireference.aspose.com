## com.aspose.cad.jasperreports.bmp package

Use these types to set BMP export options, control compression, and integrate BMP output into JasperReports pipelines. The primary exporter classes—ASBmpExporter and ASReportBmpExporter—work with ASBmpExportConfiguration and related beans to produce high‑quality bitmap files.

| --- | --- |
| [ASBmpExportConfigurationImpl](./asbmpexportconfigurationimpl/) | The BMP file format export configuration. |
| [ASBmpExportParametersBean](./asbmpexportparametersbean/) | The BMP file format export parameters. |
| [ASBmpExporter](./asbmpexporter/) | Exports a JasperReports document to BMP format. |
| [ASReportBmpExporter](./asreportbmpexporter/) | The Bmp file format exporter. Exports reports to the image formats. |
