The API lets developers embed CAD drawings directly into JasperReports templates, converting DWG, DXF, and other CAD files to raster and vector outputs such as BMP, GIF, JPEG, PNG, PDF, SVG, TIFF, WMF, and PSD. Each output format is represented by a dedicated namespace (e.g., com.aspose.cad.jasperreports.png) with a single class that provides rendering options and configuration. Common utilities and configuration settings reside in the com.aspose.cad.jasperreports.common and com.aspose.cad.jasperreports.config namespaces, while format‑specific enums are found under com.aspose.cad.jasperreports.tiff.enums.
