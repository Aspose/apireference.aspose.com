## com.aspose.cad.jasperreports.gif package

The com.aspose.cad.jasperreports.gif namespace groups the API elements required to export AutoCAD drawings as GIF images in JasperReports. It includes configuration beans, exporter implementations, and related enums to control image quality, color depth, and rendering options.

| --- | --- |
| [ASGifExportConfigurationImpl](./asgifexportconfigurationimpl/) | The GIF file format export configuration. |
| [ASGifExportParametersBean](./asgifexportparametersbean/) | The GIF file format export parameters. |
| [ASGifExporter](./asgifexporter/) | Exports a JasperReports document to GIF format. |
| [ASReportGifExporter](./asreportgifexporter/) | The Gif file format exporter. Exports reports to the image formats. |
