## com.aspose.cad.imagefilters.filteroptions package

The com.aspose.cad.imagefilters.filteroptions namespace defines concrete filter option classes derived from FilterOptionsBase, enabling fine‑tuned control over deconvolution, Gaussian, median, motion, and rectangular filters applied to CAD images. These options are used when creating filter objects to customize parameters such as kernel size, strength, and shape for optimal image enhancement.
