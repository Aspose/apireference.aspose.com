## com.aspose.cad.exporters.igesexporter.igesdrawableexporter package

The com.aspose.cad.exporters.igesexporter.igesdrawableexporter package contains the core components used by the IGES exporter, such as the IExporterVisitor interface that traverses drawable objects and generates IGES entities. Use these classes to customize or extend IGES export behavior.
