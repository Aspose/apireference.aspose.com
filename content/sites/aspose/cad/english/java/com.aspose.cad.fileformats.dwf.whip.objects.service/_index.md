## com.aspose.cad.fileformats.dwf.whip.objects.service package

The com.aspose.cad.fileformats.dwf.whip.objects.service namespace defines the core types used to represent WHIP-specific drawing attributes in DWF files. It includes font descriptors, line cap and join styles, line weights, and corresponding identifier enums for precise control over rendering.
