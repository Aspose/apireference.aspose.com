## com.aspose.cad.fileformats.ifc.ifc2x3.entities package

The com.aspose.cad.fileformats.ifc.ifc2x3.entities namespace groups Java representations of IFC 2x3 schema entities, allowing developers to create, read, and modify building information models within Aspose.CAD. It includes core classes such as IfcActor, IfcAddress, and specialized types like IfcAirTerminalBoxType for comprehensive IFC data handling.
