## com.aspose.cad.fileformats.cad.dwg package

The com.aspose.cad.fileformats.cad.dwg namespace groups the types required to read, write, and manipulate DWG CAD files. It provides utilities such as DwgVersionWriter for specifying the target DWG version when saving.
