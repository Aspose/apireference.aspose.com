## com.aspose.cad.fileformats.cad.cadobjects.dimassoc package

The com.aspose.cad.fileformats.cad.cadobjects.dimassoc namespace groups types that handle dimension association data, enabling access to linked dimension entities and their OSNAP point references. Use CadDimAssoc to work with dimension relationships and CadOsnapPointRef to retrieve precise snap point information.
