## com.aspose.cad.fileformats.iges package

The com.aspose.cad.fileformats.iges namespace groups the types that enable working with IGES files, including the IgesImage class for reading and converting IGES data to raster images. These APIs allow developers to integrate IGES support into Java applications for visualization, analysis, and format conversion.
