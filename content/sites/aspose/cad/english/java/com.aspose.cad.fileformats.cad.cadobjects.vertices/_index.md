## com.aspose.cad.fileformats.cad.cadobjects.vertices package

The com.aspose.cad.fileformats.cad.cadobjects.vertices namespace defines the core vertex types and face records that model geometric data in CAD drawings. These types are used by higher‑level CAD objects to represent points, edges, and polygon meshes in both 2‑D and 3‑D space.
