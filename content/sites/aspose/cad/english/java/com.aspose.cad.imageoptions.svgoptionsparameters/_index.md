## com.aspose.cad.imageoptions.svgoptionsparameters package

The com.aspose.cad.imageoptions.svgoptionsparameters namespace groups the types used to fine‑tune SVG generation, including font storage strategies, color handling, and image format selection. It also defines a callback interface for managing external SVG resources during export.
