## com.aspose.cad.dxf.core.watermark package

The com.aspose.cad.dxf.core.watermark namespace contains the core types used to configure and render watermarks on DXF files. Use WatermarkTextParameters to specify font, size, color, opacity, and positioning of textual watermarks.
