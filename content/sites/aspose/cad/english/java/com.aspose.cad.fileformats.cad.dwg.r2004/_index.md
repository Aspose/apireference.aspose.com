## com.aspose.cad.fileformats.cad.dwg.r2004 package

This namespace groups low‑level structures used by Aspose.CAD to read, write, and validate DWG files created with the 2004 release of AutoCAD, including checksum handling and section metadata. Developers can use these types directly when implementing custom processing or extending DWG support.
