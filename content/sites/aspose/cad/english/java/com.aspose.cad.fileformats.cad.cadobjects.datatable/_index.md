## com.aspose.cad.fileformats.cad.cadobjects.datatable package

The com.aspose.cad.fileformats.cad.cadobjects.datatable namespace defines the object model for CAD data tables, allowing developers to access table structures, rows, and column metadata. Use CadDataTable to read, create, or modify table data, and CadDataTableColumn to work with individual column definitions.
