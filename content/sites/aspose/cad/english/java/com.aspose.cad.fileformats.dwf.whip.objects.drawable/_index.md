## com.aspose.cad.fileformats.dwf.whip.objects.drawable package

The com.aspose.cad.fileformats.dwf.whip.objects.drawable namespace contains the concrete drawable types used when parsing and rendering DWF WHIP files. These classes, including DwfWhipContourSet, DwfWhipEllipse, DwfWhipFilledEllipse, DwfWhipGouraudPointSet, DwfWhipGouraudPolyline, DwfWhipGouraudPolytriangle, and DwfWhipImage, expose geometry and styling information required for accurate CAD visualization.
