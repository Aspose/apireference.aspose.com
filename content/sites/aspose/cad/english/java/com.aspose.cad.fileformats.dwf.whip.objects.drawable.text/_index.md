## com.aspose.cad.fileformats.dwf.whip.objects.drawable.text package

The com.aspose.cad.fileformats.dwf.whip.objects.drawable.text namespace groups types that model text elements within DWF WHIP drawings. It includes DwfWhipText for the text entity itself and option classes DwfWhipTextOptionBounds and DwfWhipTextOptionScoring to control layout and scoring behavior.
