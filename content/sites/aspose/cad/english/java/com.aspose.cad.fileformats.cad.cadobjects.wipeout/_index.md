## com.aspose.cad.fileformats.cad.cadobjects.wipeout package

The com.aspose.cad.fileformats.cad.cadobjects.wipeout namespace defines the CadWipeout hierarchy used to represent and manipulate wipeout entities in CAD drawings. Use CadWipeout, CadWipeoutBase, and CadWipeoutRasterImage to access properties, geometry, and embedded raster data.
