## com.aspose.cad.fileformats.ifc.ifc4.entities package

The com.aspose.cad.fileformats.ifc.ifc4.entities namespace groups Java representations of IFC4 schema objects, enabling developers to create, read, and manipulate building model data. It includes core entity classes such as IfcActor, IfcAddress, and geometric types like IfcAdvancedBrep.
