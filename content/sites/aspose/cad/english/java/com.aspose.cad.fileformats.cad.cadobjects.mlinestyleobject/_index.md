## com.aspose.cad.fileformats.cad.cadobjects.mlinestyleobject package

The com.aspose.cad.fileformats.cad.cadobjects.mlinestyleobject namespace contains the CadMLineStyleObject class, which encapsulates a multi‑line style, and the CadMLineStyleElement class, representing individual elements of that style.
