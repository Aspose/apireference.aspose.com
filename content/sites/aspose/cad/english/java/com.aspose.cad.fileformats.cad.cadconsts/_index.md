## com.aspose.cad.fileformats.cad.cadconsts package

The com.aspose.cad.fileformats.cad.cadconsts package groups together constant definitions, enumerations, and helper classes that represent CAD application codes, version identifiers, table names, attachment types, and other CAD-specific metadata. These types are used throughout the Aspose.CAD for Java library to interpret and manipulate DWG/DXF files.
