## com.aspose.cad.fileformats.cad.cadobjects.sunstudy package

The com.aspose.cad.fileformats.cad.cadobjects.sunstudy namespace contains types that represent Sun Study data embedded in CAD drawings. Use CadSunStudy to access sun direction, intensity, and related settings, and CadSunStudyDate to work with the associated date and time values.
