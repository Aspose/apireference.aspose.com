## com.aspose.cad.fileformats.ifc.ifc2x3.types package

The com.aspose.cad.fileformats.ifc.ifc2x3.types namespace defines the concrete data types used in the IFC2x3 schema, such as measures for dose, acceleration, area, and angular velocity, as well as selection interfaces like IfcActorSelect. These types enable precise modeling and manipulation of building information within Aspose.CAD for Java.
