The Aspose.CAD for Java API lets developers import, manipulate, and export a wide range of CAD and engineering file types, including DWG, DXF, DGN, IFC, STL, OBJ, PDF, SVG, and many raster formats such as JPEG and PSD. Functionality spans rendering to raster images, converting between vector and raster formats, extracting metadata, and applying image filters. All classes are grouped into 83 logical namespaces under the com.aspose.cad root, each focusing on a specific file format, export engine, or utility such as watermarking, EXIF handling, and palette management.
