## com.aspose.cad.fileformats.dwf.whip package

It includes DwfResult for operation outcomes, DwfWhipImageFormat and DwfWhipPNGGroup4ImageFormat for specifying image output, and MaterializeStage for controlling the materialization process. These types enable developers to generate WHIP‑compliant images from DWF drawings and manage the conversion workflow.
