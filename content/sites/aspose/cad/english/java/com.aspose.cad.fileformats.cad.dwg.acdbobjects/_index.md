## com.aspose.cad.fileformats.cad.dwg.acdbobjects package

This namespace groups the fundamental building blocks used by the DWG parser and writer, exposing low‑level structures that map directly to AutoCAD’s ACDB objects. Developers can use classes such as CadBlockNameEntity and the HandleCodes enum to read, modify, or create DWG entities with precise control.
