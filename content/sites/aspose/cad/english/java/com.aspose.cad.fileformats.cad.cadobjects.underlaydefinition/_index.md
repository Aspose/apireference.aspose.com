## com.aspose.cad.fileformats.cad.cadobjects.underlaydefinition package

The com.aspose.cad.fileformats.cad.cadobjects.underlaydefinition namespace groups the underlay definition classes that enable embedding external DGN, DWF, and PDF resources into CAD drawings. These types expose properties for managing file references, scaling, and visibility of underlays.
