## com.aspose.cad.fileformats.cad.cadobjects.polylines package

The com.aspose.cad.fileformats.cad.cadobjects.polylines namespace groups the core polyline-related CAD object types. Use these classes to create, modify, or query polyline, polygon mesh, and polyface mesh entities in CAD files.
