## com.aspose.cad.fileformats.cad.cadobjects.section package

The com.aspose.cad.fileformats.cad.cadobjects.section namespace groups the core objects used to define and manipulate sections within a CAD drawing. It includes geometry settings, overall section behavior, and type‑specific configuration, all accessible through the CadSectionManager.
