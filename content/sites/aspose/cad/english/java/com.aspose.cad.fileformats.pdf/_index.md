## com.aspose.cad.fileformats.pdf package

The com.aspose.cad.fileformats.pdf namespace contains types that facilitate creation and manipulation of PDF files generated from CAD models. Key classes such as PdfDocumentInfo allow you to read and set PDF document properties like title, author, and creation date.
