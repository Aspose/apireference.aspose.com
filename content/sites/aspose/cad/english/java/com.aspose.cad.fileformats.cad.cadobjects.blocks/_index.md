## com.aspose.cad.fileformats.cad.cadobjects.blocks package

The com.aspose.cad.fileformats.cad.cadobjects.blocks namespace groups types that represent block definitions, their geometric parameters, and associated actions in a CAD file. Use these types to create, modify, and query block entities, including base points, alignment grips, and custom actions.
